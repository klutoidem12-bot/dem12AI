DEMI AI — локальный демонстрационный сайт
=========================================

КАК ЗАПУСТИТЬ НА WINDOWS
1. Распакуй demi-ai-site.zip в удобную папку.
2. Открой папку demi-ai-site.
3. Дважды нажми index.html — сайт откроется в браузере.
4. Напиши сообщение в чате. Сейчас ответы демонстрационные.

ФАЙЛЫ
- index.html — разметка и содержимое сайта.
- style.css — чёрный дизайн, зелёный неон, адаптация под мобильные экраны.
- script.js — действия интерфейса и демонстрационные ответы.

ВАЖНО
Этот проект не подключён к настоящей ИИ-модели. Он работает локально и показывает
демо-ответы по нескольким типовым запросам. Для настоящих ответов нужен API и
небольшой серверный backend. Не помещай секретный API-ключ в script.js или HTML,
потому что посетители смогут его увидеть.

Внешний шрифт загружается из Google Fonts, если есть интернет; без него будет
использован системный шрифт.


НОВЫЕ РАЗДЕЛЫ
- DEMI PLUS: 500 ₸/месяц, ручное подтверждение Kaspi-перевода.
- Установить: скачивание архива проекта DEMI AI для Windows.
- Для реального автоматического приёма платежей нужна интеграция платёжного провайдера; номер телефона сам по себе не подтверждает оплату.
